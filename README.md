# CHIBANI AI — منصة ذكاء اصطناعي موحدة

واجهة محادثة متعددة اللغات بمزودين متعددين، تدوير مفاتيح تلقائي، تفكير عميق،
توليد صور، إحصاء توكنات، رفع ملفات، وخطط مجانية/مدفوعة.
مبنية بـ Next.js 14 + React 18 + CSS خالص (بدون Tailwind) وبدون أي مفتاح API مكتوب في الكود.

> **الاسم التجاري CHIBANI AI** — اسم المستودع `omni-ai-chat` ومشروع Vercel
> `omni-ai-chat-dbwk` والنطاق لم تتغير، التغيير للعلامة الظاهرة فقط.

## التشغيل محلياً

```bash
npm install
npm run dev
# افتح http://localhost:3000
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. في Vercel: New Project ← استورد المستودع ← Deploy (لا حاجة لمتغيرات بيئة).
3. المفاتيح تُدخل من واجهة الموقع (مدير المفاتيح) وتُحفظ في متصفح المستخدم فقط.

## الحصول على مفاتيح مجانية

| المزود | الرابط |
|---|---|
| Groq (الأسرع للبدء) | https://console.groq.com/keys |
| OpenRouter (نماذج :free) | https://openrouter.ai/keys |
| Google Gemini | https://aistudio.google.com/apikey |
| Hugging Face | https://huggingface.co/settings/tokens |
| Together AI | https://api.together.ai/settings/api-keys |
| DeepSeek | https://platform.deepseek.com/api_keys |

كل مزود له حدوده وحسابه الخاص. لا يوجد مفتاح واحد يفتح كل النماذج مجاناً.

## كيف يعمل تدوير المفاتيح؟

- أضف عدة مفاتيح لنفس المزود من «مدير المفاتيح».
- عند رد المزود 429 (نفاد الحصة) أو 401/5xx، يجرّب الخادم (`app/api/chat/route.js`)
  المفتاح التالي تلقائياً، ثم المزود التالي في الوضع «تلقائي».
- ترتيب الوضع التلقائي: Groq ← OpenRouter ← Pollinations ← Together ← Gemini ← DeepSeek ← Mistral ← Hugging Face ← OpenAI.
- المفاتيح لا تُسجَّل في سجلات الخادم أبداً.

## FreeLLMAPI — الراوتر المستضاف

الراوتر مفتوح المصدر (https://github.com/tashfeenahmed/freellmapi) مستضاف
على Railway ويعمل على مدار الساعة — لا Termux ولا تثبيت على هاتفك:

- رابط الراوتر العام: https://freellmapi-production-c529c3c7.up.railway.app/
  (الـ API على `/v1`).
- مفاتيح المزودين تُضاف في لوحة الراوتر (صفحة Keys)، والمفتاح الموحد
  `freellmapi-…` يُنسخ من أعلى الصفحة نفسها ويُلصق في الموقع: القائمة
  الجانبية ← «إعدادات FreeLLMAPI» ← «اختبار الاتصال».
- الطلبات تمر دائماً عبر وكيل خادم الموقع (`app/api/chat`) إلى الرابط العام —
  لا اتصال مباشر من المتصفح ولا localhost. اختر المزود
  «FreeLLMAPI Router (سحابي)» واترك النموذج `auto`.
- أرقامه المعلنة (10.1 مليار توكن/شهر / 87 مزوداً) هي **مجموع** الحصص المجانية
  لكل المزودين معاً، وليست رصيداً يمنحه لك أحد — كل مزود يحتاج حسابه
  ومفتاحه وحدوده. الكتالوج المجاني لقطة شهرية تتأخر 30 يوماً؛ الكتالوج الحي
  Premium بـ 19$/سنة (أو 49$ مدى الحياة). المشروع «للتجربة الشخصية فقط».

## ⚔️ وضع المقارنة

- فعّل «⚔️ مقارنة» من أعلى المحادثة: يُرسل سؤالك نفسه إلى عدة مزودين
  في الوقت نفسه، وتظهر إجاباتهم جنباً إلى جنب (أعمدة على المكتب، مكدّسة
  على الهاتف) — كل بطاقة تحمل اسم المزود والنموذج والتوكنات والوقت،
  والأسرع يحمل شارة «⚡ الأسرع».
- يظهر في الاختيار فقط المزودون الجاهزون فعلاً: من لا يحتاج مفتاحاً
  (Pollinations) أو من له مفتاح محفوظ، وFreeLLMAPI فقط عند حفظ مفتاحه
  الموحد. المزود بلا مفتاح يظهر معطّلاً مع «أضف مفتاحاً».
- المزود الفاشل تظهر بطاقته برسالة الخطأ الصادقة، لا بإجابة وهمية.
- توكنات كل الإجابات تُحسب في الجلسة واليوم مثل الردود العادية،
  والوضع واختيارك محفوظان في المتصفح (omni_compare_on /
  omni_compare_providers).
- إيقاف المقارنة يعيدك إلى المحادثة العادية بمزود واحد.

## ما هو تجريبي / غير مكتمل بصراحة؟

- **المصادقة:** تسجيل دخول حقيقي بـ Google OAuth عبر next-auth (v1.7) — يحتاج
  إعداد Google Cloud من مالك الموقع (انظر قسم «تسجيل الدخول بـ Google» أدناه).
  بدون بيانات OAuth يظهر زر الدخول رسالة واضحة بدل الفشل الصامت. وضع الضيف
  («تجربة بدون حساب») ما زال متاحاً. لا يوجد أي رمز تحقق تجريبي بعد الآن.
- **الدفع (v1.8):** الدفع الحقيقي بـ USDT على شبكة TRON (TRC20) — بطاقات
  أسعار أنيقة مع شعار USDT، نافذة دفع فيها عنوان المحفظة + زر نسخ + QR
  + المبلغ بالضبط + بريد المشتري + حقل TXID + زر «تحقق من الدفع».
  التحقق يقرأ سلسلة TRON مباشرة عبر TronGrid (بلا مفتاح): وجود المعاملة،
  نجاحها، المستلم، عقد USDT، المبلغ بالضبط، والحداثة (24 ساعة).
  **حد الصدق:** سجل TXIDs المستخدمة محلي في متصفح كل جهاز — منع الإنفاق
  المزدوج الحقيقي عبر الأجهزة يحتاج قاعدة بيانات مشتركة (Vercel KV أو
  Supabase) ولم يُنفَّذ بعد؛ لا يُدَّعى حماية كاملة.
- **الفيديو (v1.8):** Veo 3 و Seedance 2.5 عبر fal.ai (مفتاح واحد، تداول
  مفاتيح على 429)، و Gemini Omni Flash عبر مفتاح Gemini — غير متزامن مع
  استطلاع حالة من العميل. Replicate / Luma / Runway ما زالت خيارات.
  لا يوجد مزود فيديو مجاني موثوق بدون مفتاح، لذا يرجع الخادم
  `402` مع خطوات الحصول على مفتاح، ولا يعرض فيديو وهمياً.
- **PDF:** يُقبل كملف مرفق لكن استخراج نصه غير متوفر في المتصفح؛
  الواجهة تطلب نسخ نصه ولصقه.
- **التوكنات:** العداد تقدير محلي (~حرف = ربع توكن) ما لم يرجع المزود `usage` دقيقاً.
  **عداد الخطة اليومية (100K) يُحسب محلياً في متصفحك (localStorage) — هو
  عدّاد استخدام وليس فوترة خادم**، ويمكن تجاوزه بمسح بيانات المتصفح؛
  لا يُستخدم لحظر حقيقي على الخادم.

## تسجيل الدخول بـ Google (OAuth حقيقي — إعداد 5 دقائق)

الزر «تسجيل الدخول بـ Google» يستخدم next-auth. على Android يفتح مختار
حسابات Google في الجهاز — تظهر حسابات Gmail الموجودة على الهاتف.
الجلسة تُحفظ في ملف تعريف (cookie) آمن، فإعادة فتح الموقع تسجّل الدخول
تلقائياً، ويظهر الحساب في القائمة الجانبية مع زر تسجيل خروج.

1. في [Google Cloud Console](https://console.cloud.google.com/) أنشئ مشروعاً،
   ثم APIs & Services ← Credentials ← Create Credentials ← OAuth client ID
   ← نوع التطبيق **Web application**.
2. في **Authorised redirect URIs** أضف بالضبط:
   `https://omni-ai-chat-dbwk.vercel.app/api/auth/callback/google`
3. انسخ **Client ID** و **Client Secret**.
4. في Vercel ← مشروع `omni-ai-chat-dbwk` ← Settings ← Environment Variables،
   أضف:
   - `GOOGLE_CLIENT_ID` = القيمة من الخطوة 3
   - `GOOGLE_CLIENT_SECRET` = القيمة من الخطوة 3
   - `NEXTAUTH_URL` = `https://omni-ai-chat-dbwk.vercel.app`
   - `NEXTAUTH_SECRET` = سلسلة عشوائية طويلة (مثال: `openssl rand -base64 32`)
5. أعد النشر (Redeploy) من Vercel.

بدون هذه المتغيرات يعمل الموقع كاملاً عدا زر Google، الذي يعرض رسالة
«أضف بيانات Google OAuth في Vercel أولاً» بدل الفشل الصامت. لا يُكتب أي
سر في الكود أبداً؛ وإن غاب `NEXTAUTH_SECRET` يُولَّد سر مؤقت عند كل تشغيل
(الجلسة تعمل لكنها لا تبقى عبر إعادة النشر).

## النسخة 1.8 — دفع USDT حقيقي، Nano Banana و Veo 3 و Seedance 2.5، لوحة أدوات كل مزود

- **الدفع بـ USDT (TRC20):** بطاقات أسعار أنيقة (قيمة الخطة + الميزات +
  السعر بـ USDT + شعار USDT المضمّن SVG) في درج الأسعار. نافذة الشراء تعرض
  عنوان المحفظة مع زر نسخ و QR (حزمة `qrcode`، توليد في المتصفح) والمبلغ
  بالضبط وبريد المشتري (يُملأ من حساب Google) وحقل TXID وزر «تحقق من الدفع».
  التحقق خادمي (`app/api/verify-payment/route.js`) عبر TronGrid:
  `GET /v1/transactions/{txid}` + `GET /v1/transactions/{txid}/events` —
  يتحقق من وجود المعاملة ونجاحها وأن المستلم هو محفظة الموقع وأن تحويل
  USDT (العقد `TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t`) بالمبلغ بالضبط بالـ SUN
  وأنها حديثة (24 ساعة). عند النجاح تُفعَّل الخطة شهراً في المتصفح، وعند
  كل تحميل يُعاد التحقق من الـ TXID المخزّن فيسقط أي اشتراك مزوَّر.
  سجل TXIDs المستخدمة محلي في كل جهاز (per-device) — منع الإنفاق المزدوج
  عبر الأجهزة يحتاج قاعدة بيانات مشتركة (Vercel KV / Supabase) ولم يُنفَّذ.
- **صور Nano Banana (Google Gemini):** `gemini-nano-banana-2.1` (الأحدث،
  الافتراضي) و `gemini-3.1-flash-image` (Nano Banana 2) و `gemini-3-pro-image`
  (Pro) عبر generateContent الرسمي
  (`POST /v1beta/models/{model}:generateContent`، رأس `x-goog-api-key`،
  `responseModalities: ['TEXT','IMAGE']`، الصورة base64 في
  `candidates[0].content.parts[].inlineData.data`) — يحتاج مفتاح Gemini
  مجاني من Google AI Studio. يُختار النموذج من درج الصور أو من لوحة أدوات
  Gemini؛ عند اختيار نموذج محدد يُجرَّب وحده وإن غاب مفتاحه يرجع خطأ صريحاً
  باسم المفتاح المطلوب بدل التبديل الصامت.
- **فيديو Veo 3 و Seedance 2.5 (fal.ai) و Omni Flash (Gemini):** Veo 3 عبر
  `fal-ai/veo3` (‏4/6/8 ثوانٍ، 720p/1080p، صوت أصلي)، Seedance 2.5 عبر
  `bytedance/seedance-2.5/text-to-video` (حتى 30 ثانية، حتى 4K) — بروتوكول
  طابور fal الرسمي (`POST https://queue.fal.run/fal-ai/{endpoint}` ثم
  استطلاع `…/requests/{id}/status` ثم `…/requests/{id}`)، مع تداول مفاتيح
  fal على 429/401. Omni Flash عبر Interactions API
  (`POST /v1beta/interactions`) فيديو 3–15 ثانية بصوت أصلي بمفتاح Gemini.
  الفيديو غير متزامن: الخادم يرجع `jobId` والعميل يستطلع
  `POST /api/video/status` كل 8 ثوانٍ (حد Vercel 60 ثانية للدالة الواحدة).
  **تنبيه صادق:** Veo 3.0 GA الرسمي متاح فقط عبر Vertex AI (OAuth) لا بمفتاح
  API — مسار fal.ai يقدّم Veo 3.1 تحت الاسم نفسه؛ و Veo 3.1 Preview في
  Gemini API أُغلق 2026-10-22. مسار Omni Interactions يحتاج مفتاح Gemini
  للتأكيد الحي (شكل الاستجابة موثق في الوثائق لكن لم يُختبر حياً هنا).
- **لوحة أدوات كل مزود:** كل مزود في `lib/providers.js` له قائمة `tools`
  (الاسم العربي، وصف من سطر، الميزة الأهم، لونها: برمجة أزرق، تحليل بنفسجي،
  بحث عميق كهرماني، توليد صور أخضر، توليد فيديو وردي/أحمر، محادثة رمادي،
  مقارنة بنفسجي داكن). فوق صندوق الكتابة شريط شرائح صغير قابل للتمرير
  لأدوات المزود المحدد؛ النقر يفتح ورقة طويلة بكل الأدوات مع شارة الميزة
  بلونها، واختيار أداة يفعّل وضعها للرسالة التالية (برمجة/تحليل/بحث عميق/
  مقارنة/صورة Nano Banana/فيديو Veo 3 أو Seedance أو Omni).
- **المفاتيح المطلوبة من المستخدم (لم تُستخدم أي مفاتيح حقيقية في البناء):**
  مفتاح Gemini مجاني (Nano Banana + Omni) من aistudio.google.com/apikey،
  ومفتاح fal.ai (Veo 3 + Seedance 2.5) من fal.ai/dashboard/keys — يُضافان
  من «مدير المفاتيح»، وكل مفتاح إضافي يدخل في التناوب التلقائي.

## النسخة 1.7 — CHIBANI AI: لغات، معاينة HTML، مقارنة مطوّرة، نجوم ذهبية، Google OAuth، مهارات وربط

- **الاسم:** العلامة الظاهرة CHIBANI AI في الشعار والعنوان والترحيب وREADME.
  المستودع والنطاق ومشروع Vercel لم تتغيروا.
- **لغات (12):** العربية، English، Français، Español، Deutsch، Türkçe،
  Русский، 中文، हिन्दी، Português، Italiano، Bahasa Indonesia — من القائمة
  الجانبية أو الإعدادات (`lib/i18n.js`). يتبدل اتجاه الصفحة (RTL/LTR)
  تلقائياً، ويُحفظ الاختيار في المتصفح، ويُطلب من النموذج الإجابة بلغة
  الاختيار. أي مفتاح غير مترجم يرجع إلى الإنجليزية ثم العربية.
- **التفكير العميق:** أثناء الكتابة يظهر التفكير بنص صغير باهت شفاف
  («جارٍ التفكير…»)، وعند ظهور الإجابة يختفي ويبقى سطر واحد «عرض التفكير»
  يفتح التفكير عند النقر — لا كتلة كبيرة معتمة أبداً.
- **معاينة داخل التطبيق:** أي كتلة ```html في رد تظهر زر «👁 معاينة»
  يفتحها في iframe معزول (`sandbox="allow-scripts"`، بدون
  `allow-same-origin`) داخل نافذة ملء شاشة، مع نسخ و«فتح في المتصفح».
  الروابط العادية في الردود تفتح أيضاً داخل التطبيق في النافذة نفسها،
  مع رابط احتياطي للمواقع التي تمنع العرض في إطار (X-Frame-Options).
  كود النموذج لا يُنفَّذ أبداً في سياق الصفحة الرئيسية.
- **المقارنة:** كل بطاقة بإطار بلون علامة المزود التجارية
  (`color` في `lib/providers.js`: Groq برتقالي، FreeLLMAPI بنفسجي،
  Pollinations أخضر، OpenAI تركوازي، Together أزرق، DeepSeek بنفسجي،
  Gemini أزرق، Mistral برتقالي-أحمر، Hugging Face أصفر، Ollama رمادي).
  النقر على بطاقة يوسّعها لملء الشاشة بالإجابة كاملة. الفائز (الأسرع)
  بإطار ذهبي + شارة «🏆 الفائز» إضافة إلى «⚡ الأسرع». التوكنات والوقت
  على كل بطاقة كما قبل.
- **خلفية نجوم ذهبية:** نجوم متوهجة منجرفة خافتة (canvas) خلف الواجهة
  الزجاجية، مع مفتاح إيقاف في الإعدادات واحترام `prefers-reduced-motion`.
- **عداد الخطة اليومية:** عدّاد ظاهر في الشريط العلوي (المستعمل / 100K مع
  شريط تقدّم) إضافة إلى توكنات الجلسة. عند نفاد 100K اليومية يُعطَّل
  صندوق الكتابة والإرسال مع رسالة واضحة ونافذة خطط؛ زر الترقية يعرض
  بصراحة «الدفع غير مفعّل بعد — تواصل مع مالك الموقع» (Stripe غير متصل).
  **التنفيذ محلي من عدّادات localStorage — عدّاد استخدام وليس فوترة خادم.**
- **المهارات:** قسم «🎯 المهارات» — مهارات مدمجة قابلة للتبديل (مطوّر ويب،
  كاتب محتوى، محلل بيانات، مترجم، مدرّس) تُلحق تعليماتها بموجه النظام،
  إضافة إلى منشئ مهارات مخصصة (اسم + تعليمات، تُحفظ في المتصفح).
- **الربط:** قسم «🔗 الربط» — GitHub (Personal Access Token)، Vercel
  (token)، Render (API key)، تُحفظ التوكنات في المتصفح فقط، مع زر
  «اختبار الاتصال» لكل خدمة. قدرة حقيقية عبر `/api/connect` (بلا تسجيل
  للتوكنات أبداً): GitHub عرض المستودعات + قراءة ملف، Vercel عرض
  المشاريع، Render عرض الخدمات. عند السؤال في المحادثة («اعرض مشاريعي
  في Vercel») يُجلب السياق تلقائياً ويُضمَّن في الرسالة قبل الرد.
- **إصلاح:** حقل «نقطة نهاية مخصصة» في الإعدادات كان يستدعي دالة غير
  معرّفة (`saveCustomBase`) — عُرّفت الآن.

## النسخة 1.6 — واجهة بأسلوب Claude + توجيه ذكي + تداول مفاتيح FreeLLMAPI

- **واجهة نظيفة بأسلوب Claude:** الشريط العلوي فيه الشعار وعنوان الجلسة وزر القائمة فقط؛ الخطة والبريد وعدد التوكنات انتقلت إلى القائمة الجانبية. لا شريط أزرار مزدحم ولا قوائم تلقائي ولا أزرار تصدير في العرض الرئيسي.
- **ورقة اختيار النموذج:** اضغط اسم النموذج فوق صندوق الكتابة فتنفتح ورقة سفلية (نافذة وسطية على المكتب) — بطاقة لكل مزود مع وصف من سطر وشارة (الأسرع / الأذكى / مجاني / يحتاج مفتاحاً) وعلامة ✓ على المحدد، إضافة إلى «تلقائي» و«⚔️ مقارنة» كمدخلين.
- **زر «+» في صندوق الكتابة:** يفتح ورقة الأدوات الحقيقية فقط — توليد صورة، توليد فيديو، إرفاق صورة، إرفاق ملف، تفكير عميق، مقارنة. لا بحث ويب ولا موصلات ولا ذاكرة مختلقة.
- **صندوق كتابة فارغ تماماً:** لا يوجد أي نص شفاف (placeholder) في شريط الكتابة. الصفحة الرئيسية سطر ترحيب واحد فقط.
- **موجّه ذكي (lib/intent.js):** يفهم الأمر بالعربية والإنجليزية والفرنسية ويحوّلك للأداة المناسبة — «اريد صورة هنا» يولّد صورة فعلاً (لا يرد بنص ورابط أبداً)، «فيديو…» يذهب لأداة الفيديو، «قارن…» يفعّل المقارنة، «فكر بعمق…» يفعّل التفكير العميق لرسالتك. وتظهر شريحة صغيرة «تم التوجيه إلى: …» لتعرف السبب. اختيارك الصريح من ورقة «+» يفوز دائماً على الكشف التلقائي.
- **توليد الصور بترتيب جودة:** أولاً نموذج الصور الخاص بمزود لديه مفتاح (DALL·E 3 عبر OpenAI، FLUX عبر Together أو Hugging Face)، ثم راوتر FreeLLMAPI بمفاتيحه الموحدة، وأخيراً نموذج FLUX.1-schnell مفتوح المصدر مجاناً بدون مفتاح (مساحة Hugging Face).
- **مفاتيح FreeLLMAPI متعددة (تداول):** في «إعدادات FreeLLMAPI» أضف مفاتيح موحدة من عدة حسابات (حساب 1، حساب 2…)، مع حالة كل مفتاح (يعمل / مستنفد) وآخر استخدام. عند 401/429 أو نفاد الرصيد ينتقل الموقع تلقائياً للمفتاح التالي، وتتداول الطلبات بين المفاتيح دورياً.
- **جلسات طويلة:** تُعرض آخر 50 رسالة فقط، مع زر «عرض رسائل أقدم» لتحميل 50 أخرى؛ الجلسات والتوكنات والتصدير تعمل على الجلسة الكاملة.

## النسخة 1.6.1 — إزالة Pollinations من الصور + مسار FLUX مجاني مفتوح المصدر + ترجمة الوصف

- **Pollinations أُزيل من توليد الصور نهائياً:** كان يتدخل دائماً كملاذ أخير ويرجع صوراً خاطئة الموضوع (مثال: طلب «طائرة عسكرية جزائرية» رجع صورة امرأة بالحجاب). لا يوجد أي استدعاء لـ image.pollinations.ai في مسار الصور بعد الآن. Pollinations يبقى فقط كمزوّد محادثة نصية مجانية بدون مفتاح — شكوى المستخدم كانت عن الصور فقط.
- **تشخيص مسار الراوتر:** الكود كان يمرّر المفاتيح الموحدة ورابط الراوتر صحيحاً إلى /api/image، والمشكلة ليست في التمرير. الراوتر نفسه يدعم ‎/v1/images/generations‎ حسب توثيق FreeLLMAPI، لكنه يخدم نماذج الصور فقط إن أُضيف في لوحته مفتاح مزود يقدّمها؛ المفتاح الوحيد المضاف في الراوتر هو Groq (نص فقط)، فيردّ الراوتر 404 على نموذج FLUX، فيسقط الكود إلى البديل المجاني. الحل للمستخدم: إضافة مفتاح Together (أو غيره ممن يقدّم FLUX) في لوحة الراوتر إن أراد الصور عبر الراوتر.
- **مسار جديد مجاني بدون مفتاح:** مساحة Hugging Face مفتوحة المصدر black-forest-labs/FLUX.1-schnell عبر حزمة ‎@gradio/client‎ الرسمية (نقطة ‎/infer‎)، بمهلة ~50 ثانية؛ إن كانت المساحة نائمة أو مشغولة يرجع خطأ صريحاً ولا يرجع صورة خاطئة أبداً. **تحذير صادق:** المساحة تعمل على ZeroGPU بحصة يومية مجانية للمستخدمين بلا حساب — من عنوان IP مشترك (مثل خوادم Vercel) قد تكون الحصة مستنفدة فيرجع الخطأ «استُنفدت الحصة المجانية اليومية». المسار المجاني الموثوق هو إضافة مفتاح Hugging Face مجاني (من huggingface.co/settings/tokens) في مدير المفاتيح، فيستخدم الموقع مسار FLUX بالمفتاح.
- **ترجمة الوصف تلقائياً:** الوصف غير الإنجليزي (مثل العربية) يُترجم إلى الإنجليزية قبل التوليد عبر الراوتر أولاً ثم Groq مباشرة — best-effort، فإن فشلت الترجمة يُستخدم الوصف الأصلي ولا يتوقف التوليد. هذا يصلح السبب الأرجح للصورة الخاطئة: نماذج الصور مدرّبة على الإنجليزية.
- **ترتيب التوليد الجديد:** (أ) نموذج صور مزود بمفتاح محفوظ، (ب) راوتر FreeLLMAPI بمفاتيحه الموحدة، (ج) مساحة FLUX المجانية. الرد يسمّي دائماً المسار الذي أنتج الصورة (via) — لا استبدال صامت أبداً.
- **فشل صريح:** إن فشلت كل المسارات يرجع الخطأ بالعربية مسمّياً كل مسار وسبب فشله وما يمكن للمستخدم فعله (إضافة مفتاح OpenAI/Together/Hugging Face، أو إضافة مفتاح صور في لوحة الراوتر، أو إعادة المحاولة لاحقاً عبر المسار المجاني).
